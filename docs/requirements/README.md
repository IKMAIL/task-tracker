# Requirements Documentation

This directory stores all requirements gathering deliverables generated by the `/requirements` skill suite.

## Structure

| Directory / File | Generated By | Description |
|---|---|---|
| `business-context.md` | `/req-phase1-business` | Problem statement, objectives, KPIs |
| `stakeholder-register.md` | `/req-phase2-stakeholders` | Stakeholder register + RACI matrix |
| `functional-requirements.md` | `/req-phase3-functional` | User stories, acceptance criteria, business rules, data dictionary |
| `nonfunctional-requirements.md` | `/req-phase4-nonfunctional` | NFR spec sheet + security/compliance checklist |
| `technical-constraints.md` | `/req-phase5-technical` | Technical constraints, ADR stubs, dependency list |
| `scope-definition.md` | `/req-phase6-scope` | MVP definition, MoSCoW backlog, out-of-scope register |
| `validation-signoff.md` | `/req-phase7-validation` | Sign-off checklist, gap analysis |
| `ambiguity-log.md` | `/req-ambiguity-log` | Open questions with owners and due dates |
| `traceability-matrix.md` | `/req-traceability` | Cross-phase requirement traceability |
| `change-log.md` | `/req-change-management` | Post-sign-off change requests |

## Usage

Run `/requirements` to execute the full process, or invoke individual phase skills as needed.
